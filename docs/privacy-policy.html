Privacy Policy

Extension: Dynamics 365 Text Resizer
Last updated: 2026-06-11

Summary

This extension does not collect, transmit, store, or share any personal data or browsing data of any kind.

Data Collected

None. The extension does not collect or transmit any data to external servers.

Local Storage Only

User preferences (enabled state, minimum height, highlight toggle, custom field labels) are saved locally in chrome.storage.sync. This data is:

  • Stored only on your device (synced across your own Chrome profile via your Google account, if sync is enabled).
  • Never sent to the extension developer or any third party.
  • Limited strictly to extension settings — no page content, form values, or browsing history is ever read or stored.

Host Permissions

The extension requests access to *.dynamics.com and *.microsoftdynamics.* domains solely to inject a content script that resizes and auto-fits text fields on those pages. No data from those pages is read, captured, or transmitted anywhere.

Third-Party Services

None. The extension makes no network requests and uses no third-party analytics, tracking, or advertising services.

Contact

If you have questions about this policy, open an issue on the GitHub repository.
