Dynamics 365 Text Resizer

A browser extension that makes text fields in Dynamics 365 vertically resizable and auto-fits them to their content.

Firefox Add-on Chrome Extension Edge Add-on

Features

  • Auto-fits Description, Notes, and Resolution fields to their content
  • Vertical resize handle on all text fields
  • Supports plain textareas and Quill rich-text editors
  • Configurable minimum height
  • Add custom field labels via the popup
  • Hover highlight for enhanced fields
  • Markdown strip ("Format") button

Privacy

This extension collects no user data. See the full Privacy Policy.
